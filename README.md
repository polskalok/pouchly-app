## Features

- Track expenses with amount, category, date, note, and location
- Custom categories with an emoji picker
- History tab with date/amount filters and column, points, and pie charts
- Places tab: a map of your spending by location
- Monthly budgets, overall and per category
- CSV export
- Day / Night / Wood visual themes with adjustable frosted-glass blur
- Full English and Polish localization
- Manual and automatic (GPS) location tagging for expenses

## Install

Pouchly isn't published on the App Store or Play Store — it's a personal-use app you install directly.

- **Android:** grab `pouchly-*.apk` from the [latest release](https://github.com/polskalok/pouchly-app/releases/latest), enable "install from unknown sources" if prompted, and install it.
- **iOS:** not yet packaged for sideloading — see the release notes for updates.
